# gatos

`gatos` (Portuguese for cats) is a toy library that provides functional programming abstractions and is heavily based on [Scala Cats](https://typelevel.org/cats/).

This is highly experimental, a little playground to learn more about Category Theory, Functional Programming and abusing Rust. It's also work in progress, so use at your own peril.
